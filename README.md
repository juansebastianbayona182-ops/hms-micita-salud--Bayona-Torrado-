# HMS - MiCita Salud

## Descripción del proyecto
Plataforma web y móvil desarrollada para la IPS de la ciudad de Bucaramanga con el fin de gestionar la agenda de citas médicas, control de pacientes (afiliados y particulares), integración con pasarelas de pagos, sistema HIS y servicio de mensajería para recordatorios.
